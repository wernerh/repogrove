# DESIGN-SYSTEM.md

Not yet started — placeholder for the design lane's first run. Will define tokens
(colour, type, spacing, radius, elevation, motion) wired into Tailwind's theme config,
plus shell/layout and patterns for cards (repo/Grove cards per spec §8), tables
(alternatives comparison per spec §3–4), status chips (momentum/"Heat" — colour never the
only signal, per WCAG), and page headers.

One reversible question for the owner, to ask once with a recommended default rather than
guessing silently: overall visual direction (palette, type, density, tone). Recommended
default: a clean, content-forward editorial look (think a technical blog crossed with a
directory) — not GitHub's own visual language, so RepoGrove reads as its own product
(spec §29).
