# GLOSSARY.md

| Term | Meaning |
|---|---|
| **Grove** | A curated collection of repositories around a problem, technology, category, or ecosystem (e.g. "AI Grove"). RepoGrove's primary organising concept. |
| **Repo page** | RepoGrove's intelligence page for one GitHub repository — richer than GitHub's own page. |
| **Alternative** | A different project or product that could be used instead of a given one — open-source, free, or commercial. |
| **Momentum / Heat** | RepoGrove's transparent, multi-signal activity indicator (🔥 Rising / 🟢 Active / …), never a single opaque score. |
| **Rising** | A repo growing unusually fast, regardless of absolute size — distinct from "Trending" (biggest movers). |
| **Snapshot** | A point-in-time record of a repo's stars/forks/issues/contributors, used to compute growth. |
| **Lane** | One of the three autonomous factory roles: dev, security, design. See `CLAUDE.md` §5. |
| **Finding** | A tracked security (`SEC-YYYY-NNN`) or UX (`UX-YYYY-NNN`) issue filed by its owning lane. |
| **Walking skeleton** | The smallest end-to-end slice of the product that proves the architecture, built before deep feature work (Phase 1). |
