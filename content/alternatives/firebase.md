# Firebase alternatives

## Open source
- Appwrite
- Supabase
- PocketBase

## Commercial
- AWS Amplify

## Best fit
- Self-hosting your backend instead of a managed cloud service
- SQL-backed options (Supabase's Postgres, PocketBase's SQLite) instead of a proprietary datastore
- A single platform for auth, database, storage, and functions (Appwrite, Supabase)
- A single-binary, low-ops deployment for a small-to-medium app (PocketBase)
