# Databases

The data layer underneath everything else — storage and query engines you can run
yourself, from a single embedded file to a distributed cluster.

## Core projects
- [DuckDB](/repo/duckdb) — an in-process, embedded SQL database built for fast
  analytical queries, with no server to run.
- [ClickHouse](/repo/clickhouse) — a distributed, column-oriented database built for
  real-time analytics at very large scale.
