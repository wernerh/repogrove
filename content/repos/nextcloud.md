# Nextcloud

A self-hosted file sync, sharing, and collaboration platform that bundles calendar,
contacts, video chat, and office-document editing into one suite you run yourself.

## What it does
Nextcloud syncs files between a server you control and every device you use, the same
job Dropbox or Google Drive does — but the server is yours, and an expandable app
ecosystem (Calendar, Contacts, Mail, Talk video chat, in-browser office document editing)
turns it into a broader private alternative to Google Workspace or Microsoft 365, not
just a file drop.

## Why people use it
- Full control over where files and documents actually live, with no third-party vendor
  able to read or lock you out of them
- One suite covers file sync, calendar/contacts, video calls, and office documents
  instead of stitching several hosted services together
- A large third-party app ecosystem extends it well past storage (project boards,
  password managers, e-reading, and more)
- Deployable in whatever way fits — self-managed server, a Nextcloud-affiliated hosting
  provider, or a pre-built appliance

## Pros
- Broadest feature surface of any self-hosted productivity suite in this Grove — files, groupware, communication, and office apps all under one roof
- Fully open source end to end, with no dual-license "enterprise edition" holding features back — revenue comes from support/consulting, not withheld code
- Large, active app ecosystem and a long release history going back to 2016

## Cons
- Administrative overhead grows with usage: updates, storage planning, backups, app-compatibility checks, and performance tuning are all on the self-hoster, not a vendor
- AGPL-3.0 licensing means a company wanting to bundle or resell it commercially without AGPL's copyleft obligations needs a separate arrangement
- Heavier to run well than a single-purpose tool — a team that only wants file sync, not a full groupware suite, is paying complexity for features it won't use
