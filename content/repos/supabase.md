# Supabase

Open-source Firebase alternative.

## What it does
Supabase bundles a hosted (or self-hosted) Postgres database with auth, storage, realtime
subscriptions, and edge functions behind a single client SDK.

## Why people use it
- Real Postgres underneath, not a proprietary datastore
- Generous open-source self-hosting story
- Familiar SQL instead of a bespoke query language

## Pros
- Full Postgres feature set available
- Active development, strong community
- Self-hostable if you don't want the managed service

## Cons
- Self-hosting the full stack has more moving parts than a single-binary alternative
- Some managed-service features lag behind the hosted offering when self-hosted

## Alternatives
**Open-source:** Appwrite, PocketBase.
**Commercial:** Firebase, AWS Amplify.
